# 問卷量化整理腳本

此專案包含 `process.py` 與輔助啟動腳本，主要用於將畢業生流向與教育成效問卷（Excel 格式）進行自動化清理、量化轉換與統計摘要。

程式會自動判斷問卷版本（大學部 / 研究所 / 碩專班），將文字量表轉換為數值，並輸出包含詳細統計數據與核心能力構面分析的結果檔。

## 📥 輸入與輸出

* **輸入**：問卷原始 Excel 檔案（預設讀取第 2 列作為標題列，即 `header=1`）。
* **輸出**：檔名格式為 `<原始檔名>_Result.xlsx` 的 Excel 檔案，內含以下主要工作表：
    1.  **`原始資料`**：原始問卷數據備份。
    2.  **`個案含分數`**：包含各題項數值化（`_num` 欄位）以及各構面平均分數的明細資料。
    3.  **`題目統計摘要`**：各題目的有效樣本數、平均數、標準差、最大/最小值、4分以上比例，以及 5~1 分的各階層數量與比例。
    4.  **`核心能力`**：依據題號配對（重要性與達成度）計算的複合構面分數，並附帶詳細的計算說明與對應的 Excel 儲存格來源。
    5.  **`核心能力_學年度比例`**：依學年度彙整各核心能力的五級量表比例，並以 `5×極重要＋4×重要＋3×普通＋2×不認同＋1×極不認同` 計算可追溯的 `平均分數` 欄位。
    6.  **`核心能力_權重表`**：依學年度列出各核心能力的加權平均分數與標準差。
    7.  **年度工作表**：另依學年度輸出題目統計與核心能力明細，方便逐年檢視。

## 🎯 程式處理目標與特色

* **欄位名稱正規化**：自動處理全/半形標點符號與多餘空白，確保精準比對。
* **智慧題目對應**：使用內建的 `mapping_table` 進行直接對應；若查無完全相符者，會啟動備援機制，利用題號前綴（如 `1.1`, `4.`）及寬鬆數字匹配來抓取正確欄位。
* **文字量表數值化**：自動將「重要性」、「符合程度」、「認同程度」、「滿意度」與「幫助程度」等文字轉換為 1~5 分的量化數值。
* **多維度統計摘要**：在 `題目統計摘要` 工作表中，不僅計算基礎敘述統計（平均、標準差等），還會展開每個選項（5 分到 1 分）的填答數量與比例分布。
* **構面成績計算與追溯**：在 `核心能力` 工作表中，會針對特定的核心能力項目計算構面平均，並在「計算說明」欄位中明確列出該分數是引用 `個案含分數` 工作表中的哪些 Excel 儲存格範圍（例如 `A2:A100`），方便人工驗證與追溯。

## 🧠 核心能力構面項目

程式會根據原始檔名自動判斷問卷類型，並採用對應的核心能力構面：

**🎓 大學部**
1. 具備數理與工程知能
2. 具備設計製造與自動化專業知能
3. 具備整合與實踐工程實務之能力
4. 具備溝通表達與團隊合作之能力
5. 具備體察環境與持續成長之能力

**🔬 研究所 / 碩專班**
1. 具備精進專業知能與研究方法之能力
2. 具備規劃及執行專題研究與成果撰述之能力
3. 具備蒐尋與評述國際文獻之能力

## 📂 檔案結構與環境需求

* **主要檔案**：
    * `process.py`：核心處理腳本，包含資料清洗、統計計算與寫入 Excel 之邏輯。
    * `run_process.sh`：macOS / Linux 專用啟動腳本（自動建立 `.venv` 虛擬環境並安裝相依套件）。
    * `run_process.bat`：Windows 專用批次檔（自動建立 `.venv` 虛擬環境並安裝相依套件）。
* **環境需求**：
    * Python 3.8+（系統須具備 `python3` 或可透過 `PYTHON` 環境變數指定）。
    * 若專案內存在 `requirements.txt`，啟動腳本會自動安裝；否則預設安裝 `pandas`, `numpy`, `xlsxwriter`, `openpyxl`。

## 🚀 快速使用指南

### macOS / Linux (Terminal)

1. **直接執行**（將提示輸入檔名，或按 Enter 使用預設檔名）：
   ```bash
   bash run_process.sh
   ```
2. **帶參數指定檔案**：
   ```bash
   bash run_process.sh -f "回收問卷_大學部應屆畢業生_ReWu.xlsx"
   ```
3. **賦予執行權限後執行**：
   ```bash
   chmod +x run_process.sh
   ./run_process.sh -f "你的問卷檔案.xlsx"
   ```

### Windows (CMD / PowerShell)

1. **直接執行批次檔**（支援互動式輸入）：
   ```cmd
   run_process.bat
   ```
2. **帶參數指定檔案**：
   ```cmd
   run_process.bat -f "回收問卷_大學部應屆畢業生_ReWu.xlsx"
   ```

## 🛠️ 注意事項與常見疑難排解

* **檔名規範**：輸出檔名由原始檔名衍生，請避免在互動模式下輸入空白或無效字元，以免造成輸出檔名非預期。
* **Python 環境識別**：若腳本提示找不到 `python3` 或執行失敗，請確認系統已正確安裝 Python 3 且已加入環境變數（Path）。你也可以手動設定 `PYTHON` 環境變數指向 Python 執行檔的路徑。
* **Windows 虛擬環境**：若在 Windows 啟動 `.venv` 失敗，請確認存放此專案的資料夾路徑中沒有會導致解析錯誤的特殊字元，並確認使用者具備執行腳本的權限。
* **題目對應維護**：目前題目的對應表（Mapping）採內嵌於 `process.py` 中的方式實作。若未來問卷題目有大幅度修改，建議更新腳本內的 `mapping_table`，或考慮將其重構為外部的 `mappings.json` 以利維護。
