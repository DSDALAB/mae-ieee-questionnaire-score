# 問卷量化整理工具

此專案包含一個用於將問卷 Excel 轉為量化報表的 Python 程式與便利執行腳本。

**主要檔案**
- `process.py`：主要處理程式。功能包含：
  - 使用 `header=1` 讀取問卷（標題列在 Excel 第 2 列）。
  - 欄位正規化（統一全/半形標點與空白），並以題號優先做匹配；同時內嵌 `mapping_table` 做直接對應。
  - 把量表文字映成數值（重要性 / 達成度 / 認同 / 滿意 / 幫助等對照表在檔案內）。
  - 產生 `個案含分數`（原始題目對應 `_num` 欄位）、`題目統計摘要`（每題有效樣本、平均、標準差、最小/最大、4分以上比例，且新增 1~5 分的數量與比例；欄位順序為數量 5→1，然後比例 5→1）以及 `核心能力` 工作表（各構面統計與多行計算說明，說明包含實際 Excel 欄位與儲存格範圍）。
- `run_process.sh` / `run_process.bat`：建立或啟用 `.venv`、安裝相依套件，並執行 `process.py`。

**輸出檔案**
- 會產生 `<basename>_Result.xlsx`，包含工作表：
  - `原始資料`：原始匯入（header=1 的結果）。
  - `個案含分數`：原始題目對應之 `_num` 數值欄位與構面分數欄。
  - `題目統計摘要`：題目級統計與分數分布（數量與比例）。
  - `核心能力`：構面統計（有效樣本、平均、標準差、最小/最大、4分以上比例）與多行「計算說明」（說明使用 `個案含分數` 中的欄位與儲存格範圍）。

**快速使用**
1. macOS / Linux：
```bash
./run_process.sh -f "回收問卷_大學部應屆畢業生_ReWu.xlsx"
```
2. Windows：
```powershell
run_process.bat "回收問卷_大學部應屆畢業生_ReWu.xlsx"
```
3. 也可直接用 Python：
```bash
python process.py -f "回收問卷_大學部應屆畢業生_ReWu.xlsx"
```

若未提供 `-f`，程式會互動提示輸入檔名（按 Enter 使用預設）。請盡量用 `-f` 指定完整檔名以避免空白輸入造成空輸出名稱。

**重要實作細節與可配置項**
- 欄位匹配：程式優先使用內嵌 `mapping_table`（在 `process.py` 內），找不到時會嘗試以題號（例如 `1.1`, `2.2`）與正規化後的前綴匹配；再找不到則用寬鬆數字匹配作備援。
- 量表對照：文字→數值的映射（`map_importance`, `map_fit`, `map_agree`, `map_satis`, `map_help`）已寫在 `process.py`，如需調整可直接編輯該檔。
- `核心能力`（構面）計算：若同一構面有「重要性(_num)」與「達成度(_num)」，則個人構面分數為兩者列平均；只存在其中一個則以該欄計算。整體統計即基於此個人構面分數計算。每列的 `計算說明` 包含 `個案含分數` 的實際欄位名稱與 Excel 範圍（例如 `個案含分數!BB2:BB125`），以方便審閱與追溯。

# 問卷處理工具

簡短說明：此專案包含 `process.py` 與輔助腳本，會將問卷原始 Excel 轉成三個工作表的結果檔（原始資料 / 個案含分數 / 題目統計摘要），輸出檔名格式為 `<原始檔名>_Result.xlsx`。

主要檔案
- `process.py`：主要處理腳本，包含欄位正規化與內嵌的 mapping 資料。
- `run_process.sh`：macOS / Linux 用啟動腳本，會建立或啟用 `.venv` 並安裝相依後執行 `process.py`。
- `run_process.bat`：Windows 用批次檔，同樣建立或啟用 `.venv` 並執行 `process.py`。

需求
- Python 3.8+（系統的 `python3` 或自訂 `PYTHON` 環境變數）
- 若要手動安裝，可使用 `requirements.txt`（若存在，腳本會自動使用）。

快速使用（macOS / Linux）

1. 直接用 Bash 執行（會建立並使用 `.venv`）：

```bash
bash run_process.sh
```

2. 指定要處理的檔案：

```bash
bash run_process.sh -f "回收問卷_大學部應屆畢業生_ReWu.xlsx"
```

3. 若想讓腳本能以 `./run_process.sh` 執行，可先給予執行權限：

```bash
chmod +x run_process.sh
./run_process.sh -f "檔名.xlsx"
```

Windows（cmd / PowerShell）

1. 執行批次檔（互動或帶參數）：

```cmd
run_process.bat
rem 或
run_process.bat -f "回收問卷_大學部應屆畢業生_ReWu.xlsx"
```
